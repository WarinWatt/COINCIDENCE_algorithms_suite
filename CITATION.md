## What to report with the citation

For reproducibility, include the commit or release tag, Python/package
versions, problem instance, representation, objective definitions, population,
generations or objective-evaluation budget, reward/punishment selection ratios,
learning strength, template mode, seeds, termination rule, and whether an
accelerated or reference evaluator was used.

If a published benchmark, optional third-party evaluator, or reconstructed
legacy algorithm is used, cite its original source separately. A citation of
this repository does not replace those attributions.
